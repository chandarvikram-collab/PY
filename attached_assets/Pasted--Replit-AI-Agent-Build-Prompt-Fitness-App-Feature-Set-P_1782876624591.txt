## 1. Calorie & Macro Calculator

Implement using **Mifflin-St Jeor** for BMR, then TDEE, then goal adjustment.

```
BMR (male)   = 10*weight_kg + 6.25*height_cm - 5*age + 5
BMR (female) = 10*weight_kg + 6.25*height_cm - 5*age - 161
TDEE = BMR * activity_multiplier
  sedentary=1.2, light=1.375, moderate=1.55, active=1.725, very_active=1.9

Goal adjustment (weekly pace in lbs, 1lb ≈ 3500 kcal):
daily_calories = TDEE ± (weekly_pace_lbs * 3500 / 7)
  (+ for gain, - for loss, 0 for maintenance)

Macros:
protein_g = weight_kg * 1.6 to 2.2   (use 2.0 as default multiplier)
protein_cal = protein_g * 4
fat_cal = daily_calories * 0.25      (25% default, allow 20-30% range)
fat_g = fat_cal / 9
carb_cal = daily_calories - protein_cal - fat_cal
carb_g = carb_cal / 4
```

**Onboarding questions to collect (drives the calc above):**
1. Age
2. Biological sex (male/female — needed for BMR formula)
3. Height (cm or ft/in toggle)
4. Weight (kg or lb toggle)
5. Activity level (sedentary / light / moderate / active / very active)
6. Primary goal (fat loss / muscle gain / maintenance / endurance)
7. Weekly pace (e.g., -0.5 to -2 lbs/week for loss, +0.25 to +0.5 for gain)
8. Available equipment (multi-select array)

**Equipment constraint rule:** exercise/routine generation must never reference equipment outside the user's selected list. If "Bodyweight only" is selected, restrict to calisthenics/tempo/HIIT — no barbells, racks, cables, machines.

Build this as a pure function (`calculateNutrition(profile)`) that's unit-testable and callable both from onboarding and from a "recalculate" settings action later. Store the result on the user profile record.

## 6. Running Calories Burned (MET formula)
